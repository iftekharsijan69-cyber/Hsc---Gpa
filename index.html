How HSC GPA is calculated

Each subject's marks become a grade point (A+ = 5.00, A = 4.00, A− = 3.50, B = 3.00, C = 2.00, D = 1.00, F = 0). Add the grade points of your main subjects, add the 4th subject points above 2, then divide by the number of main subjects. The highest GPA is 5.00. A fail (F) in any main subject means no GPA.
